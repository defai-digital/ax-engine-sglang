1. **CONFIRMED — [phase1/eval_tokenizer.py:115](/Volumes/Ext16TR0/code/ax-engine-sglang/phase1/eval_tokenizer.py:115), [track_a/run_ncm.sh:69](/Volumes/Ext16TR0/code/ax-engine-sglang/track_a/run_ncm.sh:69): tokenizer gate is disabled.** Both configs specify `final_level: tokens`, making gate threshold/pass `None`; evaluation exits successfully regardless of reconstruction. A read-only probe reproduced this with 10% accuracy. The script then marks `DONE` and launches expensive drafter training. **Fix:** implement the decision’s explicit 99% gate / 97% rejection threshold and propagate failure before training drafters.

2. **SUSPECTED — [phase2/eval_drafter.py:145](/Volumes/Ext16TR0/code/ax-engine-sglang/phase2/eval_drafter.py:145): verifier parity is assumed.** Evaluation compares drafts against stored vLLM responses; it never checks the HF verifier’s greedy logits. Different execution kernels can produce different argmax sequences, invalidating “exact” acceptance against that verifier. **Fix:** establish token-level parity with the intended serving verifier, or perform actual greedy verification, comparing prediction at position `s−1` against draft token zero.

3. **SUSPECTED — [phase2/drafter.py:359](/Volumes/Ext16TR0/code/ax-engine-sglang/phase2/drafter.py:359), [phase2/drafter.py:100](/Volumes/Ext16TR0/code/ax-engine-sglang/phase2/drafter.py:100): serious OOM/throughput risk.** At configured maximum shapes, expanding 16 windows into 512 blocks creates **5 GiB** of FP32 memory; six layers produce **30 GiB** of bf16 cross-attention KV, before normalization intermediates/backward. FP32 token logits alone require **15.16 GiB**, plus cross-entropy storage and the frozen 27B. KV projections repeat identical work 32 times. **Fix:** project KV once per window, microbatch blocks while sharing encoder memory, and chunk/fuse vocabulary loss. Measure a full training/validation peak before launch.

4. **CONFIRMED — [track_a/run_ncm.sh:64](/Volumes/Ext16TR0/code/ax-engine-sglang/track_a/run_ncm.sh:64), [track_a/configs/ncm_b32_k6.yaml:17](/Volumes/Ext16TR0/code/ax-engine-sglang/track_a/configs/ncm_b32_k6.yaml:17): stale artifacts can silently change the experiment.** `DONE` ignores requested steps/config/data changes; blocks are skipped solely on `meta.json`. Moreover, overriding `ROOT` leaves tokenizer checkpoint paths pointing at `/dev/shm/ax`. **Fix:** validate completion against config/data/checkpoint identities and completed steps; resolve tokenizer paths from the selected run root.

5. **CONFIRMED — [phase2/drafter.py:398](/Volumes/Ext16TR0/code/ax-engine-sglang/phase2/drafter.py:398): code and token levels are not equally weighted.** Code losses are normalized together, while token loss retains weight 1. Each K6 code level therefore receives weight `1/6`, versus 1 for the token level; K5 changes that ratio. **Fix:** normalize all levels together, or multiply aggregate code weight by K to implement the documented equal-level recipe.

6. **SUSPECTED — [phase1/vqvae.py:137](/Volumes/Ext16TR0/code/ax-engine-sglang/phase1/vqvae.py:137): coarse codebook restarts may churn healthy codes.** EMA updates occur per microbatch: level zero averages only `256/8192 = 0.03125` assignments/code, below restart threshold `0.05`. Balanced usage cannot keep every code above that threshold. **Fix:** scale thresholds by assignments per level/update, lower the coarse threshold, and inspect restart counts.
