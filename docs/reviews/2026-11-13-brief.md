# Design review request: "ax-engine-sglang" — converting Qwen3.6-35B-A3B into a Next-Concept Model (NCM)

You are a senior ML research engineer reviewing a design. Be critical and concrete. Do NOT write code. Answer in <= 900 words, using the numbered sections at the bottom.

## Background: NCM (arXiv 2610.14162, Hazy Research, Oct 2026; code github.com/HazyResearch/ncm, MIT)
- Stage 1 tokenizer: multiscale residual VQ-VAE (6 layers, dim 384) maps a FIXED-length token sequence (L=1024 for OWT) into K levels of discrete codes, with level lengths growing coarse to fine (OWT: 32 levels, lengths 1,4,9,...,1024 (squares), codebook 8192 per level; WMT14: 11 levels 1..64, codebook 4096). Nested dropout so any prefix of levels decodes. Reconstruction accuracy 98.8-100%.
- Stage 2 generator: ~100M-param transformer (OWT: 16 layers, d=1024). Input = upsampled cumulative reconstruction of coarser levels; predicts all codes of the next level in parallel. Attention pattern "block_diagonal" over levels, prefix-LM for prompts, heads tied to codebooks, trained on all levels in one forward pass with CE + conditioning corruption. K forward passes per sequence.
- Results vs diffusion LMs: LM1B 21x faster at better gen-PPL; OWT ~10x; XSum 31x at matched ROUGE-L; WMT14 BLEU 22.6 @11 NFE vs AR 25.2 @64 (MBR reaches 25.2 @132); Sudoku beats AR and DLMs. Speedups were measured only vs diffusion, not vs optimized AR. Only tested at <=725M params, sequences <=1024.

## Base model: Qwen/Qwen3.6-35B-A3B (Apache-2.0, ~36B params, ~3B active)
config: 40 layers, hidden 2048; layer_types = 3x Gated-DeltaNet linear attention then 1x full attention, repeated (30 linear + 10 full); full attn 16 Q heads / 2 KV heads, head_dim 256, partial RoPE 0.25, attn output gate; linear attn 16 K heads/32 V heads dim 128, conv kernel 4; MoE 256 experts top-8 + shared expert, moe_intermediate 512; vocab 248,320; 1 MTP layer; max pos 262k; plus a 27-layer vision tower (multimodal).

## Proposed design (draft by Claude)
Core problem: NCM is fixed-length, non-streaming; an LLM must produce open-ended long outputs. So:

Design "Block-NCM" (semi-autoregressive):
1. Qwen remains an autoregressive backbone over COMMITTED context (prompt + already-generated blocks), with its KV cache / DeltaNet recurrent state.
2. Each new block of B tokens (B=64..256) is generated NCM-style: K≈8-12 levels coarse-to-fine, each level in parallel. So per block ≈ K forward passes instead of B.
3. Tokenizer: new block-level multiscale residual VQ-VAE over Qwen's 248k vocab, codebooks 8192/level, trained on in-domain (code/math/chat) Qwen-tokenized text. Target >=99.9% token reconstruction since one wrong token breaks code.
4. Generator = Qwen backbone with: input projection from code embeddings to 2048, level embeddings, per-level heads tied to codebooks. In-block attention: full-attn layers use a flex-attention mask (attend to all context + coarser levels + same level, block-diagonal). Gated-DeltaNet layers are causal recurrences — proposal: start from the cached context state and run a bidirectional (forward + backward scan) pass over the in-block level tokens, backward branch initialized from forward weights. Alternative: replace in-block DeltaNet op with small dense attention over the block (B is small).
5. Keep Qwen LM head + AR loss so the same model can VERIFY a decoded block in one parallel pass (speculative-decoding style accept/reject), giving an AR-quality fallback and a lossless mode.
6. Training: (0) train tokenizer; (1) freeze Qwen, train new adapters/heads/backward-DeltaNet on ~1-5B tokens; (2) full fine-tune with mixed NCM + AR loss on 20-50B tokens, preferably self-distilled from Qwen3.6 outputs (chat/code/math); (3) SFT/RL. Drop the vision tower for v1.
7. Alternative low-risk track A: small separate NCM model (~0.5-1B) as a block DRAFTER for unmodified Qwen3.6 (speculative decoding) — lossless, much cheaper.

Hardware options: RunPod 8x H200 (141GB each) or 8x B200 (~180GB each). Rough estimate: full FT of 36B MoE in bf16 + AdamW ≈ 580GB states + activations -> fits 8x H200 with FSDP/ZeRO-3 + expert parallel; ~30B tokens x ~3x positions (all levels) x 6 x ~3.5B active ≈ 2e21 FLOPs; at 25% MFU ≈ 11 days on 8xH200, ~5 days on 8xB200.
